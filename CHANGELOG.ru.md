# Журнал изменений

В этом файле описаны изменения `displayctl`.

[English changelog](CHANGELOG.md)

## 1.0.2 — 2026-09-30

- Исправлено определение Adaptive Sync при отсутствии необязательного
  интерфейса VRR. Режимы с фиксированной частотой в этом случае остаются доступны.
- Яркость и Night Shift подтверждаются двумя последовательными совпадающими
  показаниями. Стабильное значение подтверждается за 0,3 секунды вместо
  обязательного ожидания 0,6 секунды; отсутствующие и временные показания
  не принимаются за подтверждение.
- Получение прошивки ограничено пятью секундами. Устранён риск блокировки
  процесса при сборе его вывода; метаданные не выводятся, если их нельзя
  однозначно сопоставить с монитором.
- `info` продолжает работать при ошибках таблиц профилей, частот или разрешений.
  Причина выводится в тексте и необязательном массиве `warnings` в JSON.
- Системные сервисы инициализируются только по необходимости; исключено чтение
  цветовых настроек при изменении не связанных с ними параметров.
- Разделены парсер команд и локализованная справка; синтаксис команд сохранён.
- Добавлены 34 регрессионных теста и их запуск в GitHub Actions.

## 1.0.1

- Добавлены русский и английский языки вывода и документации.
- Добавлены команды для просмотра информации о дисплеях, прошивки, серийного
  номера, яркости, референсных профилей, частот, разрешений Retina, раскладки
  и зеркалирования.
- Добавлены блоки настроек для отдельных и нескольких дисплеев.
- Добавлены ручной и автоматический режимы яркости.
- Добавлено управление True Tone и Night Shift с проверкой совместимости профиля.
- Добавлены JSON-вывод и проверка команд без применения изменений (`--dry-run`).
- Добавлена проверка сборки Release в GitHub Actions.
